## Question

Which application entry points must the first release support, and which require UI design?

The latest discussion identified:

- Applying a template to an existing job.
- Applying a template while creating a new job.
- Applying a template through an upload.
- Applying a template through an integration.

Decide:

- Which of these are MVP requirements?
- Which need a designed user interface and which can be API or operational capabilities?
- Should all entry points expose the same preview, scaling, deadline, and feasibility behaviour?
- Where does the user choose the template when creating a new job?
- What does upload or integration need to return when application fails or produces infeasible demand?
